# V010：作物结构第一阶段

本阶段只改变 `CROP_MIX`：

- `v010a_crop_mix`：完全移除胡萝卜；
- `v010b_carrot_half`：移除一半胡萝卜配额；
- `control`：根目录当前 baseline。

没有加入肥料、牲畜扩容、路线、任务优先级或新市场逻辑。评测新增了根目录 baseline 作为直接 opponent，每个候选覆盖 5 类对手、6 个 seeds、两个 seat，共 60 局。

所有 180 局均为 `DONE`，错误数和非法动作数均为 0，p99 单回合耗时约 1.3ms。

## 结论

V010A 的“胡萝卜清零”过于激进：草莓数量增加，但 `WATER`、`HARVEST` 下降，`PASS` 上升，说明当前调度器无法支撑新的草莓结构。V010B 更稳定，但仍未达到晋级条件。

因此不 promotion，根目录 `main.py` 保持不变。下一阶段应先优化高价值作物的维护和收获利用率，再重新尝试作物结构调整。
