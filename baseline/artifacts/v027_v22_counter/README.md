# V027：针对 v22 同构路线的商品级销售错位

## 状态

这是基于 v22 的下一轮实验设计，当前只记录方案，不替换根目录
`main.py`。v22 仍然是 control。

## 动机

v22 的生产路线和单位调度已经是当前本地最强部分。对其 SELL 时间线做检查
后发现，MELON 的销售集中在少数几个波次，最容易被采用同一完整路线的对手
同步复制。STRAWBERRY 次之；MILK 和 WOOL 的销售更分散，第一轮不做大幅
调整。

V027 不改变生产结构，只在已有 premium `SELL` 订单之间重新分配数量：

```text
v22 固定路线
→ 商品销售波次错位
→ v22 原有 price-impact 排序
```

## 候选

### v027a_melon_ratio

只调整 MELON。当前订单最多提前卖出下一次 MELON 原计划数量的 25%，下一次
原有订单扣除相同数量，因此总销售量不变。只有在价格至少为基础价 105%、
市场库存低于初始库存、当前库存充足、且存在未来原计划订单时才执行。单次
最多提前 6 个，商品冷却 8 回合。

### v027b_mirror_gated

在 v027a 上增加公开状态门控。第 8 天和第 12 天检查对手是否呈现 v22-like
结构：12～14 个 hands、NE/SW 已解锁、约 7～9 头牛、5～7 只羊，并且没有
明显低产结构。两个检查点都命中后才进入 `MIRROR_MODE`；连续两个日边界
偏离后退出。未识别到同构路线时完全回退 v22。

### v027c_product_specific

在 v027b 上加入小幅商品消融：MELON 最多提前下一订单的 25%，STRAWBERRY
最多提前 12.5%；MILK 和 WOOL 第一轮保持 v22 原动作。每回合最多调整一个
商品，step 648 后关闭动态数量调整，step 672 后完全回退 v22。

## 不变量

- 不创建原计划中不存在的 premium `SELL`；
- 当前订单增加量等于未来同商品订单减少量；
- 不改变 farmer/hands、种植、浇水、收获、喂养和购买路线；
- 不改变非 premium 订单及 BUY/HIRE/BUY_LAND/BUY_PRODUCT；
- 市场订单最多 10 个，SELL 数量不得超过合法库存；
- 不读取选手身份、分数、seed、replay 或网络；
- 终局阶段优先使用 v22 原始动作。

## 评测重点

除常规终局现金、W/T/L、DONE、异常和耗时外，记录：

- 每种商品原计划/实际 SELL 数量；
- 提前销售、未来订单扣减和实际成交价格；
- 市场价格断崖及恢复；
- `MIRROR_MODE` 命中和退出次数；
- 与 v22 的逐回合 action diff；
- 同构公开状态和非同构公开状态下的分别表现。

只有在总体胜率不下降、最低现金不明显变差，并且同构路线对手下的平均
现金差有稳定改善时，才生成提交包；否则继续保留 v22。
